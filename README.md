# Task Manager App

A simple task management app built with **React, TypeScript, Vite, and Tailwind CSS**.

## Features

* View tasks in individual cards
* Filter tasks by status and priority
* Update task status
* Delete tasks
* Color-coded task priorities
* Display task due dates

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS

## Components

* `App` – Manages tasks, filters, and task actions
* `TaskFilter` – Filters tasks by status and priority
* `TaskList` – Displays the list of tasks
* `TaskItem` – Displays an individual task card
